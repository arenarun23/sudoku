# 스도쿠 (AI Edu 허브)

2×2부터 16×16까지 단계별로 푸는 학습용 스도쿠입니다. 빌드가 필요 없는 정적 사이트라서 Vercel에 그대로 배포됩니다.

## 기능

- **단계**: 크기 15종(초급 2–4, 중급 5–8, 고급 9–12, 최고급 13–16) × 난이도 3종(쉬움·보통·어려움)
  - 상자 모양: 4×4(2×2), 6×6(3×2), 8×8(4×2), 9×9(3×3), 10×10(5×2), 12×12(4×3), 14×14(7×2), 15×15(5×3), 16×16(4×4)
  - 2·3·5·7·11·13은 직사각형 상자를 만들 수 없어 가로·세로만 겹치지 않으면 되는 규칙입니다.
  - 10~16은 A~G로 표시합니다.
- **난이도 기준**: 빈칸 수와 함께 필요한 풀이 기법으로 나눕니다.
  - 쉬움: "하나만 남은 칸"만으로 풀립니다.
  - 보통: "유일한 자리"까지 써야 풀립니다.
  - 어려움: 유일해만 보장합니다.
- **문제는 매번 난수로 섞습니다.** 해답 판을 만든 뒤 행·열·숫자를 `crypto.getRandomValues`로 섞고, 빈칸도 무작위 순서로 지우면서 매번 유일해인지 검사합니다.
- **3단계 힌트**: 1 살펴볼 곳 표시 → 2 쓸 기법 안내 → 3 정답 칸과 이유. 힌트를 쓴 횟수에 따라 별 수가 달라집니다.
- **저장과 이어하기**: 숫자를 쓸 때마다 자동으로 저장하고, 10초마다, 탭을 닫거나 숨길 때도 저장합니다.
  처음 화면이나 단계 선택에서 다음 중 하나를 고를 수 있습니다.
  - 멈춘 곳부터 이어하기
  - 같은 문제 처음부터
  - 새 문제 섞기
  - 처음부터 시작(2×2 쉬움부터)
- **학생별 기록**: 한 기기를 여러 학생이 쓸 수 있도록 학생마다 진행도와 저장을 따로 둡니다.
- 메모(후보 숫자), 후보 자동 표시, 틀린 숫자 표시, 검사, 되돌리기, 키보드 조작, 다크 모드를 지원합니다.

## 저장 위치

브라우저 `localStorage`(`aiedu.sudoku.v1.*`)에 저장합니다. 같은 기기의 같은 브라우저에서만 이어 풀 수 있습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 화면 |
| `js/engine.js` | 문제 생성, 풀이, 힌트(화면과 독립) |
| `js/worker.js` | 문제 생성을 별도 스레드에서 실행 |
| `js/app.js` | 화면 동작, 저장, 진행도, 단계 해금 |

## 로컬 실행

```bash
python3 -m http.server 8000
```
